# ML06ops_Experiments_with_MLflow

## Project Summary

### What is this project?
This is a short learning project about keeping track of machine-learning experiments.

### Why is it interesting?
When you try several model settings, it is easy to forget which results came from which run.

### How does it work?
MLflow records information about model experiments so runs can be compared.

### Real-life example
You train a model with two different settings and look up their recorded results instead of relying on memory.

### What did I learn?
I practiced tracking and comparing machine-learning experiments.
