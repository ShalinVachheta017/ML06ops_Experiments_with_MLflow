# ML06ops_Experiments_with_MLflow

## Project Summary

Imagine training the same model many times with different settings. After a while, it becomes difficult to remember which version gave the best result. This small learning project explores how to record machine learning experiments instead of keeping notes by hand.

The exercise uses MLflow to track model runs and compare their recorded information. For example, you can look back at two experiments and see which settings were used. I learned why experiment tracking makes machine learning work easier to understand and repeat.
